## Desafios Técnicos Reais

> Problemas complexos que enfrentei em produção e como resolvi.

<details>
<summary><strong>⚡ Otimização de Latência em IA Generativa</strong></summary>

**Problema:** Fluxos de IA generativa levavam até 15 minutos para responder em ambiente de produção.

**Solução:** Refatorei a arquitetura de prompts com técnicas de Prompt Engineering avançadas, eliminei queries redundantes no backend e otimizei o pipeline de chamadas à API.

**Resultado:**
- ✅ **97% de redução** no tempo de resposta
- ✅ **60% menos queries redundantes** no backend

</details>

<details>
<summary><strong>🔗 Integração de Sistemas Legados sem Documentação</strong></summary>

**Problema:** Conectar 4 sistemas distintos via Webhooks e APIs REST sem documentação clara, garantindo integridade dos dados em tempo real.

**Solução:** Engenharia reversa dos endpoints, mapeamento de contratos de dados, implementação de camada de normalização e retry com backoff exponencial.

**Resultado:**
- ✅ **Eliminação de 25h/mês** de trabalho manual
- ✅ **15+ fluxos críticos** 100% automatizados

</details>

<details>
<summary><strong>🛠 Redução de Downtime em Sistema RPA</strong></summary>

**Problema:** Sistema RPA com 35h/mês de downtime — interrupções constantes em integrações com APIs de terceiros. 

**Solução:** Refatoração do código Python com Docker, implementação de monitoramento proativo via Linux CLI, estratégias de retry e fallback para alta disponibilidade.

**Resultado:**
- ✅ **93,5% de redução em downtime** (35h → 2,25h/mês)
- ✅ **800+ transações/dia** processadas com estabilidade

</details>
